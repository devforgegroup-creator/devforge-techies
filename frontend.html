CURRICULUM

What's inside the path.

Eight modules, building from fundamentals to a shipped capstone project.

01

Foundations of the Web

How browsers render pages, and how HTML, CSS and JavaScript work together.

02

Semantic HTML & Accessibility

Writing meaningful markup that works for every user and every device.

03

CSS & Responsive Layout

Flexbox, Grid and mobile-first design for interfaces that adapt anywhere.

04

JavaScript Fundamentals

Variables, functions, logic and the building blocks of interactivity.

05

The DOM & Browser APIs

Manipulating pages, handling events and working with real browser data.

06

Version Control with Git

Tracking changes, branching and collaborating like a professional developer.

07

Intro to Frontend Frameworks

Component-based thinking and a first look at modern tooling.

08

Capstone Project

Design, build and ship a complete frontend project for your portfolio.
