WHAT YOU'LL LEARN

✓ Understand mobile app architecture

✓ Work with device features and APIs
✓ Manage app state and navigation

CURRICULUM

What's inside the path.

Eight modules, building from fundamentals to a shipped capstone project.

01

Foundations of Mobile Development

How mobile apps are structured and how they differ from the web.

02

Building Mobile UIs

Screens, layouts and components for phones and tablets.

03

Navigation & App State

Moving between screens and managing data as users interact.

04

Working with Device Features

Camera, location, notifications and other native capabilities.

05

Connecting to APIs & Backends

Making apps talk to real data and services.

06

Local Storage & Offline Support

Keeping apps useful without a constant connection.

07

Testing, Debugging & Performance

Making sure your app is reliable before it ships.

08

Capstone Project

Design, build and prepare a complete mobile app for release.
